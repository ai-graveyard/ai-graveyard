# 贡献指南

报告问题时，请提供浏览器和设备、页面尺寸、画质、操作步骤、期望行为和实际结果。涉及路线或碰撞时，可补充关卡、模式、障碍和触发位置；涉及界面时，截图有助于复现。

修改前先按 [README](README.md) 跑起游戏。提交前运行 `node --test tests/*.test.mjs`，并说明手动验证了哪些页面或交互。如果修改触控、面板或 HUD，请在 390×844 与 320×568 尺寸检查；如果修改渲染，请同时检查默认画质、流畅画质、减少动态和暂停。

新增资源使用本地相对路径，说明来源和适用的许可证。请保留当前入口的普通脚本加载方式，避免加入运行时依赖、外部服务或与修改无关的旧包、录屏和本机配置。
