# 运行环境与存档

游戏主体可在普通浏览器中独立运行。原项目也适配了小红书小工具宿主；宿主是否注入 `window.xhs.miniTool`、客户端版本和接口是否可用，由运行环境决定。这个项目目录不包含线上账号、服务端或线上榜单数据。

| 能力 | 普通浏览器 | 原小红书宿主适配 |
| --- | --- | --- |
| 进度、金币、荣誉、设置 | 浏览器 `localStorage`，键名 `river-3d-v1` | 优先使用可用的宿主 Storage；旧版本走本地存储降级 |
| 距离与金币榜 | 仅显示本地个人纪录 | 通过宿主读取榜单、同步正式局最好成绩；练习不提交 |
| 关注福利「缤纷乐园」 | 显示平台提示 | 通过宿主查询关注状态，确认后领取 |
| 振动与安全区 | 基础布局；无宿主振动 | 接口可用时使用宿主振动和窗口信息 |

浏览器存档按站点来源隔离。换端口、换浏览器或清理站点数据可能看不到原记录。页面本身不直接请求外部服务；榜单同步由宿主接口完成。榜单沿用距离榜 1 与金币榜 2：界面以米、枚显示，提交距离时换算为千米，保留宿主已有最高成绩。

本目录是供阅读与开发的源码。若要另行部署到小红书，先按[官方容器文档](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)与上传页的当期说明准备专用包，只收集入口和运行资源，并分别验证模拟器、Android 和 iOS。普通浏览器检查无法替代这些验证。
