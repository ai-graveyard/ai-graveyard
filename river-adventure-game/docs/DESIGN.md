# 漂流大冒险 · 3D 设计规范

本文件记录本项目的界面、交互和美术规范，供修改功能或制作资源时参考。

改动设计时请同步更新本文。查看[开发与验证](DEVELOPMENT.md)了解如何复现画面和记录验证结果。

## 1. 设计方向

- **轻松的河谷冒险**：草帽船长、动物搭子、原木筏、青绿河水与自然河岸构成统一世界。
- **暖纸与轻木框**：奶油纸面、蜂蜜木边、柔和高光和短下沿阴影，让控件有轻微厚度。避免雕花、绳结和密集木纹占据阅读空间。
- **清楚的行动层级**：橙金用于开漂、继续、重玩等主要行动；森林绿配金边用于选中、确认完成；普通操作使用浅木色。
- **河面优先**：HUD靠边、提示短小，优先保证船身、前方航道、障碍与落点可辨认。详细统计与收集说明放入弹框。
- **全局一致**：设置、指南、荣誉、排行、暂停、结算与过场复用同一套控件表面及状态。

## 2. 色彩与材质

共享控件变量维护在 [controls.css](../controls.css)。新增控件优先复用现有变量；页面专属颜色应属于相同色系，并说明用途。

| 用途 | 当前基准 | 使用规则 |
| --- | --- | --- |
| 暖纸底 | `--control-paper: #fff8e8` | 信息底色；结算纸面使用 `#fff6e5` |
| 正文深绿 | `--control-ink: #254332` | 按钮文字与主要信息 |
| 木色线条 | `--control-line: #a87a47` | 控件边线；通用面板外框使用 `#bb945f` |
| 普通按钮表面 | `--control-wood-face: linear-gradient(#fff5d7,#f3dfb5)` | 菜单、次要操作、未选中分类 |
| 普通按钮边线 | `--control-wood-edge: #b18b58` | 配合浅木色下沿，保留按压厚度 |
| 选中表面 | `--control-selected-face: linear-gradient(#33715f,#255b4a)` | 当前分类、当前船只及完成操作 |
| 选中边线／文字 | `--control-selected-edge: #dfbe78` / `--control-selected-ink: #fff4d5` | 金边与奶油字共同表达选中 |
| 主要行动 | `linear-gradient(#ffcd76,#f4a45d)`，文字 `#542e20` | 与普通、选中按钮明确区分 |
| 浅绿衬底 | `--control-wash: #e7eddb` | 分组、辅助信息与进度衬底 |
| 危险文字 | `--control-danger: #8c2f22` | 危险、失败与不可逆操作提示 |
| 禁用表面 | `--control-disabled-face: linear-gradient(#eeece1,#e1dfd1)` | 同时使用禁用边线 `#bdb69d` 和文字 `#72715d` |

木框以 2–4px 为主，通用卡片采用 4px 暖木外框、16px 圆角；按钮常用 12–15px 圆角。结算等专属卡片可以沿用当前已确认尺寸，不强制抹平页面差异。阴影表现边缘厚度与层级，不能盖住文字或相邻按钮。

## 3. 字体与信息层级

沿用系统中文字体，不引入远程字体：

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif;
```

- 页面标题通常 22–27px；普通按钮 14–16px；主要行动 17–23px。
- 正文通常 12–14px，行高约 1.6–1.8；10–12px 仅用于次要标注，不承载关键操作要求。
- 航程、金币、分数等数字优先于单位和说明。动态统计使用等宽数字 `font-variant-numeric: tabular-nums`，防止数值变化引起跳动。
- 结算距离可放大显示，长数字和短屏使用已有降字号、换行规则，保证数字与单位完整。
- 图形Logo保留原字形和比例；功能文字使用HTML，便于缩放、换行和辅助阅读。

## 4. 控件规范

### 按钮与状态

所有可点击目标至少 **44×44 CSS px**；常规操作行优先 48px 高。画面中的小图标可以更小，真实点击范围不能随之缩小。

| 类型／状态 | 表现 |
| --- | --- |
| 普通 | 奶油木色渐变、木边、浅高光与可见下沿 |
| 主要行动 | 橙金表面、深棕文字、较强下沿；一个操作区域突出一个主要行动 |
| 选中 | 森林绿表面、金边、奶油文字；同步 `aria-selected` 或 `aria-pressed` |
| 按下 | 下移约 1–3px，压短下沿阴影；松开恢复 |
| 禁用 | 纸灰表面、灰木边及柔和文字，保留可读性；真实禁用交互 |
| 键盘焦点 | 清晰绿色焦点环，不被容器裁切 |

通用按钮与状态由 `controls.css` 负责。页面样式负责排布和必要的尺寸差异，避免另造一套按钮或覆盖掉选中、禁用、按压反馈。

### 间距与布局

- 同行操作通常留 10–12px 间隔，包含可见下沿的空间，不能让两枚按钮的阴影粘连。
- 设置偏好列表沿用 `--control-list-gap: 14px`，完成按钮前沿用 `--control-stack-gap: 16px`；设置分组间距 22px。
- 并排按钮等宽、顺序与阅读顺序一致；长文案可正常换行，不能挤掉相邻操作。
- 开关同时表达位置和状态，文字说明保持清楚；画质等多值选项显示当前值。
- 重置等操作先展示具体影响并二次确认；保留明确的取消选项，不能只靠颜色区分。

## 5. 页面与信息架构

### 首页与品牌

- 游戏名称固定为「漂流大冒险」，3D为版本描述；首页主操作为「开漂」。
- 无尽模式入口从首次进入就显示在「开漂」下方。未解锁时显示本地Lucide lock-keyhole SVG与「无尽模式」，不在入口下方展示解锁说明。点击入口（含锁图标）打开居中弹框，提示先完成普通模式前4关；支持「知道了」、Escape、遮罩关闭，焦点返回入口，不启动游戏、不修改解锁存档。普通四关全部完成后将锁替换为20px本地金色闪电图标（`assets/game/endless-lightning.svg`），与标题间隔8px，副标题为「36m/s 弹射起步 · 快来挑战」，点击直接开始独立无尽局；首页允许在短屏内滚动。
- 首页关注福利未领取时显示领取卡片；领取保存成功后改为「切换船只」，展示当前船名与实际模型缩略图，直接打开船只选择面板，关闭回到首页并恢复入口焦点。领取保存失败时保留明确的保存重试入口。
- 当前首页与实玩页眉共用 `assets/brand/title-buddies-v3.webp`；由 `brand.css` 控制尺寸。保持原比例、透明边缘和完整名称，不重新生成字形。
- 首页标题与实玩页眉标识按状态互斥，单个视图不重复堆放主Logo。结算木筏章属于页面主题插图。
- 船长保持草帽、棕发、珊瑚红领巾与原木筏身份；模型帽徽、品牌插图的修改需保持识别一致。

### 实玩HUD

- 左上展示距离、实时速度与追赶状态；距离、追赶卡片同宽，单位与数字层级统一。右侧保留金币等收集反馈。
- 左侧搭子栏放在追赶条之后，采用约72px宽的无吊绳木牌。每位只显示头像、时间条与「踢」按钮，名字及操作含义保留在可访问标签中。
- 搭子按钮保留44×44点击范围；龟龟头像可作光学尺寸补偿。单人自然收短，无人隐藏；分割线与行间距仅出现在两位可见搭子之间，首位可见搭子顶部不留线或空行；最后5秒时间条转为琥珀色。
- 连击和冲浪提示使用既有底部状态区，按情境出现；不常驻大段说明、不遮挡路线。
- 当前冲浪由连续5枚金币或3连击自动触发；提示与指南不得恢复已移除的上滑释放或独立冲浪按钮。
- 追赶危险同时使用文字、数字、进度和颜色；减少动态时仍可辨认危险程度。

### 暂停、结算与详情

- 暂停突出「继续漂流」；「回到首页」「玩法指南」并排，其余操作按当前布局整行展示。
- 结算保留「成绩／收获」双Tab，首屏展示本局核心结果与重玩行动。
- 普通四关完成后，MVP提示无尽解锁；结算显示显著的浅绿金边邀请和橙金「挑战无尽模式」，并保留「回到首页」及「再闯四关」。保存期间先完成本局保存，再启用挑战；保存失败提供重试，不强制进入无尽。短屏聚焦挑战时允许卡片滚动，保证挑战和返回可操作。
- 无尽结算显示生存秒数与本局距离／金币，重玩仍为无尽。窄HUD的大数使用万／亿／万亿缩写并提供完整可访问标签，结算和存档保留完整整数；短屏的大成绩采用上下布局，不能把数字挤入普通模式的双列布局。
- 成绩页展示距离、分数、金币及连击／空翻／搭子表现；收获页突出本局金币，以简短标签展示新增船只／徽章，用一条进度说明呈现下一艘船的解锁目标。
- 收获页最多显示一个奖励入口：保存成功后优先「查看新船」，没有新船时按需显示「查看新徽章」；没有新增奖励时不补入口。排行榜从首页进入，不在收获页重复展示。
- 使用 `assets/game/result-raft.svg` 木筏河浪章和绿色标题区。「新纪录」只在严格超过历史最好时显示。
- 成绩页「回到首页」与「查看详情」并排；收获页仅保留重玩、回首页和按需出现的单一奖励入口。详情独立弹框，仅补充绕行、送鱼与委托完成数，避免重复首屏统计。
- 保存状态清晰可见，失败时保留重试；打开详情或切换Tab不能丢失状态。关闭详情后回到原Tab和原焦点。

### 设置、指南与收藏

- 设置按当前船只、游戏偏好、练习／指南、记录重置分组；船只展示图使用实际运行模型，不能用概念图冒充可用外观。
- 偏好行用浅纸色细木边；重新练习与玩法指南用普通浅木按钮，完成用绿色金边按钮。短屏内部滚动，完成操作保持可见。
- 重置学习记录确认成功后回首页，不自动强制开启完整课程；保留手动单项图解练习。
- 指南使用分类、图解与实操入口；荣誉册和排行榜分类复用共享按钮状态。
- 排行榜保留距离／金币双榜，普通四关与无尽正式结算共同上榜（榜位1／2，保留历史单位）；沿用原榜并保留云端历史最高分，规则标明“保留历史成绩”，不再展示四关版仅记个人纪录。未支持或未授权时显示个人纪录降级。
- 当前24枚荣誉图使用 `assets/brand/honors-v2/c01.svg` 至 `c24.svg`：金币厚边、主题珐琅底、简化浮雕图案。锁定通过降饱和度与文字表达，不另做一套纹理。

## 6. 3D场景、角色与动效

- 保持风格化低多边形场景、圆润角色与自然配色。通过轮廓、明暗和适度材质区分木筏、水体、角色及障碍，避免过强塑料反光。
- 航道与危险先于装饰：河岸、桥梁、浪峰、水花与投射提示不能遮住换道判断、起跳点和落点。
- 阴影跟随物体位置、离水高度和朝向，帮助判断船体接触与腾空；不使用错位阴影制造悬浮感。
- 船桨、手臂、船体及搭子保持接触与动作连贯；新增姿态检查接缝、穿模和两档画质。
- 鳄鱼保持半浸水游泳；张嘴联动头、颈背、胸腹与前腿，尾部稳定。咬船时按真实上下牙与船体接触表达夹住，再进入咬碎阶段。
- 鳄鱼上下颚采用有厚度变化的连续弧面：上颚饱满、吻端圆收，下颚中段微弯、前端轻翘，避免长直平板轮廓。牙齿、鼻孔、嘴缘与鳞片贴合同一曲面，低画质仍保留弧形轮廓；曲面调整后重新核对牙根嵌入及实际咬船接触。
- 上下牙列使用相同牙距并错开半个牙距，闭口时牙齿交错，牙尖不刺入对侧牙龈。口腔采用下凹口底、拱形上膛与相接嘴缘，张嘴幅度为0时吻端闭合；牙根、嘴线及咬船接触按两档实际三角网格定位，保留张开时可辨认的上牙，不能靠隐藏牙齿实现闭口。
- 开场先在同一镜头交代木筏领先、鳄鱼闭嘴追逐。鳄鱼随后突然加速追近、张嘴，下颚在接近船尾前下沉，并以短水花与低吼加强速度变化。开场演示不推进实际成绩与奖励。
- 追近时镜头平滑推向贴水近景，把鳄鱼的眼睛、牙口和船尾放在同一画面。鳄鱼连续收嘴，牙齿和木板保持净空。木筏先提速，船尾脱离后收嘴动作顺势接上快咬。合嘴瞬间配短促小幅震动、水花和本地合成音效。近景留到合嘴后极短一拍，随后平滑拉远跟上船，接入正式视角。开场动效不改变追逐数值。减少动态沿用跳过开场，渲染器停用额外推进、震动与粒子。
- 浪峰是接入河面的连续实体涌浪：船先沿浪面抬升，到浪尖再离水。普通空格跳与浪跳共用高度预算，不叠加高抛。
- 碎白泡沫贴合浪面、不规则分布，飞溅沿弧线落回；避免整齐白边、矩形水面接缝。浪峰经过后继续存在，离开镜头才裁剪。
- 冲浪水花采用短尾迹，动作反馈短促清楚。低画质减少细节数量；减少动态停止非必要摆动、闪烁与粒子动画，同时保留关键反馈。
- 暂停冻结游戏与相关动效；开场和终章保留跳过。兼容系统 `prefers-reduced-motion` 与游戏内 `.reduced-motion`。

### 功能旗帜

- 正式路线采用四种功能旗，每关两面，靠近自动拾取并挂上船，不新增技能按钮。疾风为珊瑚红燕尾／双箭头，丰收为蜂蜜金方旗／金币，聚宝为薄荷绿三角旗／磁铁，护航为海盐蓝盾旗／盾牌勾。聚宝的界面磁铁图标采用透明背景，不添加绿色方块或外框，使用红色「＋」端、蓝色「－」端、浅金属色U形本体与少量绿色磁力线；两极须靠颜色和符号共同区分，22px HUD尺寸也保留清楚轮廓。色彩、轮廓、图案和文字共同区分用途。
- 船上只保留一面旗、一个旗子效果；新旗拾取当帧清除旧旗的全部能力、庆祝与飞行反馈，再启用新旗；同种重新计时。丰收已经到账的金币保留，其他非旗子的冲浪、伙伴等机制照常。疾风增加4米/秒、持续3秒，与其他短时加速取较强值并遵守本关速度上限。丰收立即增加8金币。聚宝持续8秒，保留原左右吸金范围；在船经过时也能吸取上下方的水面与空中金币，垂直范围以拾取中心（船高＋1米）计，上下各一条航道宽（3.7米）。磁铁吸来的金币不推进五连冲浪，实际直接碰到的金币仍按原规则计算。护航10秒内挡一次障碍，优先于龟龟消耗；不保护失误落水或被鳄鱼追上，撞击仍计入碰撞和荣誉统计。
- 第一关先疾风、后丰收；第二关聚宝、疾风；第三关护航、聚宝；第四关确定性混合四种，以疾风和护航为主。原金币、搭子、障碍、浪峰、岸边与飞石坐标不因新增旗子改变；旗子继续满足15米混合拾物间距，疾风前方保留反应空间，聚宝后安排原有金币串。
- 右上金币区域下方最多显示一条旗子提示：当前计时卡、丰收即时金币反馈或前方拾旗提示择一显示。当前旗子生效时，不再堆放前方旗子或额外吸金通知；金币总数照常更新。所有旗子HUD卡片共用112×48 CSS px、12px文字与22px图标基线（接近提示只显示文字）；丰收与计时卡等宽等高，不单独放大字号、边框或图标。计时卡仅显示图标、用途和下方进度条，不再显示秒数或倒计时文字；护航的一次抵挡规则保留在首次说明与无障碍描述中。丰收显示「丰收金币」，下方横排8枚小金币，不再显示「＋8」，不常驻空槽。辅助读取仍提供剩余时间与准确金币数量。前方拾旗提示只留旗名与换道方向，不重复用途和时长。
- 丰收旗面与金币图案保持固定，不随时间摆动；金币竖纹须与金币底图分层，避免重叠面引起闪烁。拾取飞行与一次性到账反馈沿用现有流程。
- 暂停冻结能力、换旗和相关收集动效，减少动态保留文字和静态状态，两档画质复用原几何缓冲。外观可保存，能力仅本局拾取生效，不随已保存旗面在新局自动获得；练习收益不带回正式冒险。原六款存档编号保持兼容，未出现在功能路线的旧装扮仍可读取。

- 特效必须表现具体因果：疾风显示红色前进箭头和宽白尾浪；丰收展示8枚金币飞入船；聚宝在船旁展示绿色底座、浅金属色U形磁铁，红色「＋」端与蓝色「－」端及少量浅绿磁力线保持两档画质可辨认；旗面上的磁铁使用同样的双色双极标识。吸到的水面与空中金币沿带绿光的弧线飞入；护航显示蓝色罩弧与盾牌，抵挡后碎开。拾取旗面适度放大，飞行起点与实际浮标位置一致，碰撞窗口保持模型值。换旗当帧收起旧旗面，新旗飞抵后才挂上船，飞行期间不同时保留旧旗。
- 每种功能旗首次遇到时在安全状态暂停，使用本地图标、简短标题、一条效果、一句拾取说明与单一「知道了」按钮讲解；已拾取时按钮为「继续漂流」。说明卡的标题、效果和拾取说明统一居中，包含已拾取后的补讲说明。不再重复描述颜色、金币飞行或特效过程。阅读期间船、鳄鱼、能力、当前练习与相关特效冻结；确认后清除按住/换道输入再继续。危险、横风或腾空期间先延后，错过接近窗口则在拾取后的安全时机补讲。
- 四种功能学习记录独立于旧拾旗换装记录，确认后保存，学过后只留轻提示；已被换下的旗子不再补弹过期教学，保存失败本次不重复打断并明确提示。练习不消耗正式功能学习机会，退出练习保留原局待讲解状态；重置学习记录同时清除四种功能记录，保留金币、外观、徽章和历史成绩。

### 关卡学习与路线可读性

- 无尽从第四关36米/秒起步，每游玩1秒基础速度增加0.12米/秒，暂停与后台冻结加速；鳄鱼同步加速，保留追赶和翻船失败。路线按固定坐标滚动生成，不结算虚拟关卡，不触发四关终点、靠岸场景或终章镜头；关卡类徽章仍在普通模式完成。
- 跳跃教学统一为主动轻点起跳、稳稳落水后完成；单纯换道或被浪峰带起不能代替跳跃实操。图解、沿途提示与完成反馈使用同一口径；普通避障仍可换道。
- 普通第一关前两次获得自救支持的无搭子翻船，前进速度损失减到1米/秒，成功扶正后的2米/秒提速维持2秒；使用原有自救次数、最短恢复时间与20米追逐上限。第二至四关、无尽和单项练习保持原恢复规则。
- 第一关先练换道、金币、轻跳与水獭；借浪、鸭鸭缓降、龟龟挡撞和靠岸从第二关出现。第三关先体验横风，再出现岸边飞石；第四关只组合已经出现的机制并增加压力。
- 全关先规划固定距离坐标，再按前方距离生成；冲浪、失速不得挪动已经显示的物体或将后续障碍插入奖励位置。
- 不同金币组、搭子与旗帜的最近距离至少15米，组内五枚连续金币不受此限制。逐枚核对金币串与障碍；摆动原木按最大摆幅核对，并给拾物前后的换道留出空间。
- 浪前与落点不放地面奖励，靠岸保留对应列。相邻障碍行的安全列最多移动一列。
- 水中固定礁石有低矮板礁、较高尖礁和双道长礁三种轮廓，分别使用浅灰、冷灰和中灰，局部带低饱和苔色。水中礁石的材质独立于河岸配色。默认、低画质和减少动态共用轮廓及贴水阴影，礁脚浸入水面。
- 第二关起，部分礁石行用一个连续的长礁替换相邻两条受阻航道上的两块礁石。保留原畅通航道和前后避让距离。长礁按一个障碍结算，可走空道或轻点跳过。碰撞宽度覆盖原两块礁石的范围，奖励及浪峰继续按相同避让范围布置。
- 原木障碍使用浅色去皮木和棕色断枝木两种。每种有长短、粗细的细微变化，同排两根略微前后错开并朝不同方向斜放。年轮和贴水阴影跟随朝向，底部略浸水。外观按障碍行和原航道确定，摆动和暂停时保持同一款式，碰撞按原有航道范围处理。
- 第三关、第四关和无尽的飞石在可航行位置落下。密集障碍段把落点安排在两组障碍之间，瞄准上一组的畅通航道，避开浪峰起落区及对应的岸边任务航道。船接近时才掷出，沿落点所在航道直行会受击，可提前换道或轻点起跳避开。
- 飞石预警只在实际落点画一层小幅、柔边的水面阴影，去掉圈线、十字、箭头和额外 HUD 提示。默认、低画质和减少动态均保留静态阴影，暂停冻结投掷进程。
- 飞石采用不对称的岩块轮廓和哑光切面，飞行时缓滚。少量同材质碎石从后缘依次脱落，各自散开并落水。低画质减少碎粒，减少动态保留静态岩块和落点淡影。碎粒只作视觉表现，碰撞以主石为准。
- 第二关碰撞后继续向前漂移并可扶正，避免学习期突然停船；第四关保留高压追逐，通过正常操作存在完成路径，不按玩家身份或固定样本强制失败。

## 7. 移动端适配与可访问性

- 以竖屏触摸为主要布局，沿用单一竖屏游戏场，不另造桌面或横屏信息架构。
- 基础核对视口为390×844与320×568；弹框额外检查320×480，并覆盖顶部44px／底部24px安全区场景。
- 顶部同时考虑原生预留区 `--top-clear` 与安全区，底部操作考虑底部安全区；不能只按无刘海截图定位。
- 小屏优先减少空白、装饰与重复说明，再调整字号；保持44px触控目标，禁止靠整体缩小解决拥挤。
- 首页和长内容弹框允许滚动；结算核心操作应优先在首屏可见，详情及列表使用内部滚动。任何视口不得横向溢出。
- 背景装饰与纯提示不能吞掉河面手势；换道与跳跃支持既有双指交互，不相互取消。
- 图标按钮有明确 `aria-label`；弹框有标题和对话框语义，支持既有Escape、焦点限制与关闭后焦点返回。
- 关键反馈同时提供文字／状态，不能只依赖颜色或动效。装饰图使用空alt，承载含义的图片提供对应说明。

## 8. 文案规范

- 首页无尽模式解锁后的副标题固定为「36m/s 弹射起步 · 快来挑战」，无障碍说明同步；实际速度与加速规则以模型和指南为准。

- 使用简短、具体的中文，按钮以行动命名：「开漂」「继续漂流」「回到首页」「玩法指南」「查看详情」。同一目的全局同名。
- 普通模式为四关流程；首页、教学、奖励、结算和终章使用「关」「四关通关」「再闯四关」。无尽为通关后独立解锁的挑战，使用「无尽模式」「持续加速」「再挑战无尽」；不出现第五关或重复四关完成奖励。
- 金币、连击、冲浪、送鱼与徽章说明必须对应实际触发条件；数值改动同时核对指南与反馈。
- 提示先告诉玩家发生了什么或下一步做什么，避免把引擎、夹具、存储接口等实现细节带入正常流程。
- 保存失败、取消、未解锁和新纪录使用各自真实状态，不把准备完成写成已经获得或已保存。
